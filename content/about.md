I'm a backend engineer who gets unreasonably excited about distributed systems, clean APIs, and making things go fast.

Over the past 5 years, I've built systems that process **100M+ tokens daily**, architected document pipelines handling **100K documents/day**, and led teams shipping GenAI solutions to production. Currently obsessed with Golang, gRPC, and making observability less painful.

## What I've Built

### @ Tune AI (formerly NimbleBox.ai)

**Engineering Team Lead** — *2024–2025*

Led a document processing system that chewed through **100K documents daily** with batch inference. Cut costs by **54%** while keeping precision-recall at **95%**. Worked with a UAE-based event management company to ship a GenAI architecture that reduced proposal creation time by **20%** and automated **40%** of their workflow.

**Senior Software Engineer** — *2021–2023*

Built the gRPC backbone for a model serving system handling **100M tokens/day** — latency dropped **40%**. Created a reusable cron scheduler that killed **70%** of boilerplate scheduling code. Led the OpenTelemetry adoption across services because debugging distributed systems without traces is pain.

**Deep Learning Engineer** — *2020–2021*

Where it all started. Built ML pipeline orchestration, containerized model serving with FastAPI, and learned that production ML is mostly plumbing.
